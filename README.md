# Jumpstart Haven Project
A project made for Jumpstart Haven!
You are an asteroid on a quest to destroy ships! Explore the map and find the ship, collide with it to destroy it.

## Demo Link
You can find the demo link [here](https://gurmehar-singh-2009.itch.io/jumpstart-haven-project).

## Tech Stack
The [Godot](https://godotengine.org) Game Engine was used to create this game!
